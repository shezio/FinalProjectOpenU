1C. The one hole still open — Pillow BLOCKED

🔴 Pillow is stuck at an old version — on purpose

The security fix for Pillow only exists in version 12. But two AI-video libraries (python-pptx and moviepy) refuse to run with Pillow 12 — so bumping it alone breaks the build.

Good news — the risk is small: Pillow is only used by the admin-only AI-video feature that's effectively unused. It's not on any public or busy path.

Two ways to close it (this is a decision, not just a version bump):

  • (a) Retire the AI feature — then Pillow, python-pptx, moviepy, gTTS all get deleted and the security problem disappears with the code. Cheapest. (Waiting on the product owner — see AI_CHATBOT_PRODUCT_REVIEW_HE.html.)
  • (b) Upgrade the whole video stack — Pillow 12 + newer python-pptx + a compatible moviepy, tested end-to-end. That's the "video stack" item down in Tier 2.

What we keep on purpose (and why)

  • Python 3.11 — supported until 2027. No reason to jump; a Python upgrade touches everything.
  • apscheduler 3.x — version 4 is a ground-up rewrite of our scheduler, and there's no security reason to do it.
  • react-router 6 — already compatible with React 19.
  • The SameSite = "Lax" cookie setting — load-bearing. Changing it once broke Google login. Do not touch.
